# VoicePilot 语音实时助手 — 需求开发文档

> 求职作品集项目（AI 应用开发工程师）· 版本：v0.3.0（M3 实时链路）
> 一句话：浏览器录音 → 流式 ASR → LLM 流式回复 → 流式 TTS 的实时语音对话闭环，语音触发工具调用。

## 一、项目定位

### 1.1 背景
DocMind 覆盖「视觉 + 文本」离线重理解；VoicePilot 覆盖「音频 + 流式」实时轻交互。两者共同构成多模态 AI 应用叙事，覆盖两类高频面试题：离线 RAG/解析 与 实时流式/低延迟音频。

### 1.2 目标用户
- 演示场景：无任何 API Key 也能跑通完整语音对话（浏览器原生 ASR/TTS 兜底）
- 真实场景：接入 DeepSeek/OpenAI 兼容 LLM + 厂商 ASR/TTS，语音触发日程、提醒、天气等工具

### 1.3 成功标准
1. 打开页面 → 点击录音 → 说话 → 文字实时回显 → LLM 流式回复 → TTS 语音播报，全程 < 3 秒首字延迟（本地/演示模式）
2. 全程无 Key 可演示（规则回声 + 浏览器原生能力）
3. 对话可回听、可复制、可清空；会话历史持久化

## 三、里程碑规划（M1~M6）

### M1：骨架与语音管道（本文档交付范围）
目标：录音上传 → ASR 适配层 → 文本回显（规则回声即可跑通）。

功能点：
- [x] 工程骨架：monorepo（backend/ + frontend/），FastAPI + Vue3 + Vite + Element Plus
- [x] 后端：POST /api/audio/transcribe 上传音频 → 返回 ASR 文本 + 耗时 + 引擎名
- [x] ASR 适配层：Provider 抽象（transcribe 接口）+ RuleEchoProvider（演示兜底）+ 配置切换
- [x] 音频校验：格式白名单（webm/ogg/wav/mp3/m4a）、大小上限（20MB）、空音频拒绝
- [x] 会话存储：SQLite sessions/messages 基础表，每次转录落库（会话 id + 角色 user + 文本）
- [x] 前端：录音按钮（MediaRecorder + getUserMedia）、录音状态机、上传后回显转录文本
- [x] 权限与降级：拒绝麦克风时给出明确提示 + 文本输入兜底入口（M2 完整实现）
- [x] 质量门禁：pytest（健康检查/上传校验/ASR 回声/落库）+ ruff + vitest + build

验收标准：
1. 浏览器点击录音 → 说话 → 停止 → 页面出现转录文本（规则回声：如 "（演示）已识别 X 秒语音，共 N 字节"）
2. 非白名单格式/超大文件/空音频返回 422 与中文错误提示
3. pytest 全绿（≥10 用例）、ruff 无告警、前端 build/vitest 通过
4. 转录记录写入 SQLite，重启后仍在

### M2：对话引擎与工具调用
功能点：
- [x] LLM 适配层（复用 DocMind 模式）：OpenAI 兼容 + 规则降级问答
- [x] 多轮上下文：消息表完整落库，上下文窗口裁剪（token 估算）
- [x] 工具注册表：工具 schema（日程/提醒/天气/搜索占位实现），LLM 返回 tool_call 时执行
- [x] 敏感操作二次确认：前端确认弹窗 → 确认后执行并回填结果
- [x] POST /api/chat/messages 流式接口（SSE）+ 会话列表/详情/删除 API
- [x] 文本输入兜底正式实现（无麦克风也能完整对话）

验收标准：
1. 语音/文本输入 → LLM 流式回复完整呈现，无 Key 时规则回复可用
2. "帮我设个 9 点的提醒" → 工具调用 → 前端确认 → 写入本地提醒存储
3. 多轮对话上下文正确（能引用前文）
4. 会话可新建/切换/删除，刷新后历史保留

### M3：实时链路（WebSocket + TTS）
功能点：
- [x] WebSocket /ws/chat：双向流（客户端音频分片 → 服务端 ASR 增量 → LLM 增量 → TTS 音频帧）
- [x] 流式 ASR：增量结果（partial/final），演示模式模拟增量
- [x] 静音检测（VAD）：RMS 能量阈值，自动分段/自动停止
- [x] 打断（barge-in）：播放 TTS 时检测到人声立即停止合成并进入新请求
- [x] TTS 适配层：speechSynthesis 优先（浏览器端零成本）/ edge-tts / 厂商 API 流式
- [x] 自动重试：断线指数退避重连，状态提示

验收标准：
1. 边说边出字（partial 结果实时更新）
2. TTS 播放中说话 → 立即打断并开始识别新内容
3. 断网重连后会话上下文不丢
4. 全程无 Key 演示可跑通

## 四、技术架构

```
浏览器 (Vue 3 + Vite + Element Plus + WebAudio)
  │  MediaRecorder 录音 · speechSynthesis 播放 · WebSocket / REST
  ▼
FastAPI 应用层（audio / chat / sessions / settings / health）
  │
  ├─ ASR 适配层：RuleEcho（演示）→ Web Speech(浏览器端) / FunASR / 厂商 API
  ├─ LLM 适配层：OpenAI 兼容（DeepSeek 等）+ 规则降级
  ├─ TTS 适配层：speechSynthesis(浏览器端) / edge-tts / 厂商 API
  ├─ 工具层：工具注册表（日程/提醒/天气/搜索）+ 二次确认
  └─ 存储：SQLite（sessions/messages/tool_calls）+ 文件目录（音频片段）
部署：Docker Compose（Nginx 同源反代 /api + /ws）· GitHub Actions CI
```

技术栈：Python 3.11 · FastAPI · SQLite · Vue 3 · Vite · Element Plus · WebAudio · Docker · GitHub Actions
（可选）edge-tts / faster-whisper 本地模型

## 五、API 设计

### M1 范围
| 方法 | 路径 | 说明 | 请求 | 响应 |
|---|---|---|---|---|
| GET | /api/health | 健康检查 | - | {status, version, asr_engine, capabilities} |
| POST | /api/audio/transcribe | 上传录音转写 | multipart: file, session_id(可选), duration(可选) | {text, engine, duration, elapsed_ms, session_id} |
| GET | /api/sessions | 会话列表 | - | {total, items:[{id, title, created_at, message_count}]} |
| GET | /api/sessions/{id}/messages | 会话消息 | - | [{id, role, content, created_at}] |

### M2 追加
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/chat/messages | SSE 流式对话（含工具调用链） |
| POST | /api/sessions | 新建会话 |
| DELETE | /api/sessions/{id} | 删除会话 |
| GET/PUT | /api/settings | 引擎配置（LLM/ASR/TTS），API Key 脱敏 |
| POST | /api/settings/test | 连接测试 |

### M3 追加
| 方法 | 路径 | 说明 |
|---|---|---|
| WS | /ws/chat | 双向流：音频分片 → ASR 增量 → LLM 增量 → TTS 帧 |

## 六、数据模型（SQLite）

```sql
sessions(
  id INTEGER PK,
  title TEXT,
  created_at TEXT,
  updated_at TEXT
)
messages(
  id INTEGER PK,
  session_id INTEGER FK → sessions.id,
  role TEXT,            -- user / assistant / system / tool
  content TEXT,
  audio_path TEXT NULL, -- M4 回听
  tool_calls_json TEXT NULL,
  duration_ms INTEGER NULL,
  created_at TEXT
)
settings(key TEXT PK, value_json TEXT)
```

## 八、非功能需求

1. 安全：上传文件扩展名白名单 + 大小限制；API Key 脱敏存储展示；SQL 全参数化；路径防穿越；CORS 仅允许同源/本地开发端口
2. 性能：演示模式首字 < 3s；音频分片 ≤ 5MB/片；转录接口超时 30s
3. 兼容：Chrome/Edge 优先；不支持 MediaRecorder 时提示并降级文本输入
4. 可维护：ruff 0 告警、pytest 全绿、组件化前端、docs/ 沉淀审查报告

## 九、质量门禁（每个里程碑强制）

- 后端：pytest 全绿 + ruff check 0 告警
- 前端：vitest 全绿 + vite build 成功
- 提交规范：`feat: M{n} ...` / `fix: ...`，M 里程碑后打 tag
